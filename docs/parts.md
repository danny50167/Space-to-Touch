# 준비물 목록

✅ = 이미 있음. **필요 시점** 열을 보고 급한 것부터 주문한다.
3주차(10/26)까지 필요한 부품은 **국내 쇼핑몰**(1~3일 배송)에서 산다. 해외 배송은 2~3주가 걸려 일정에 맞지 않는다.

## 0. 이번 주: 가진 부품 점검

주문하기 전에 가진 부품부터 확인한다. 불량을 늦게 발견하면 교체품을 기다리느라 일정이 밀린다.
점검 결과는 맨 아래 **점검 기록표**에 적고, 같은 내용을 설계 일지에도 남긴다.

### VL53L1X 모듈 ×6
- [ ] 판매 페이지에서 **모델명**을 확인한다. 이름이 비슷한 **VL53L0X**(최대 약 2 m, 라이브러리가 다름)와 헷갈리기 쉽다.
- [x] 입력 전압: **5 V 호환 확인** (10/11) → 센서 VIN은 아두이노 5V에 연결한다. 레벨 변환 모듈은 필요 없다.
- [ ] 센서 창에 붙은 **보호 필름**(노란색 또는 투명)을 뗀다. 붙어 있으면 필름에 반사된 빛 때문에 거리가 짧게 나온다.
- [ ] 핀헤더가 납땜되어 있는지 확인한다. 핀을 구멍에 꽂기만 하면 접촉이 불안정해서 측정이 끊긴다 → **납땜이 먼저**다.
- [ ] `firmware/00_i2c_scan`으로 **6개를 하나씩** 검사한다 (주소 0x29, "VL53L1X 확인"이 떠야 한다).
  이번 주 목표는 1개 작동 확인이지만, 6개를 모두 확인해 두면 불량품을 일찍 교체할 수 있다.

### TCA9548A 멀티플렉서
- [ ] A0·A1·A2가 GND에 연결되어 있는지 확인한다 (주소 0x70).
- [ ] 핀헤더 납땜
- [ ] `00_i2c_scan`에서 "0x70 TCA9548A"가 보이는지 확인한다 (센서 연결 전에도 확인 가능).

### Arduino Mega, Uno
- [ ] USB 케이블 확인 (Mega와 Uno 정품은 USB-B 단자)
- [ ] 예제 Blink 업로드 → 보드와 컴퓨터 연결 확인

### 진동 모터 → 모듈로 교체 (10/12 결정)
처음 산 코인 모터는 리드선이 너무 가늘어 피복을 벗기거나 납땜하기 어려웠다.
→ **구동 회로(MOSFET)가 내장된 진동 모터 모듈**로 바꾼다. 납땜이 필요 없고, 트랜지스터 구동 회로 6세트를 만들 필요도 없어진다.
(이 과정도 설계 일지에 "부품 선정 시행착오"로 남긴다.)

- 구매: 디바이스마트 [아두이노 진동모터 모듈 ELB060416](https://www.devicemart.co.kr/goods/view?no=1312092) × 8 (6 + 여분 2)
- 판매 페이지에서 확인한 것: "MOS tube high level trigger, low level cutoff"(IN이 HIGH면 켜짐), 핀 **VCC · GND · IN**, 기판에 장착 구멍 있음

도착하면:
- [ ] 판매 페이지와 모터에서 **정격 전압, 정격 전류, 회전수(rpm)** 를 찾아 기록한다.
  - 회전수로 **예상 진동수 = rpm ÷ 60** 을 계산해 둔다 (물리 탐구의 비교 기준).
- [ ] 기판을 보고 **MOSFET과 다이오드**를 찾아 회로도를 직접 그린다 (`docs/wiring.md` 2장).
- [ ] 장착 구멍 지름과 구멍 사이 간격을 캘리퍼스나 자로 잰다 → PLA 모터 홀더 설계에 쓴다.
- [ ] `03_motor_localization_test`의 `1`~`6` 명령으로 8개를 하나씩 돌려 본다 (배선은 `docs/wiring.md` 2장).
- 기존 코인 모터는 버리지 않는다. 인두로 선 끝을 달궈 납이 묻으면 물리 실험용 예비로 쓸 수 있다.

### 스마트폰 (phyphox)
- [ ] phyphox를 설치하고, 가속도 센서의 **측정률(Hz)** 을 확인한다.
  - 진동수를 제대로 재려면 측정률이 **예상 진동수의 2배 이상**이어야 한다 (표본화 정리).
  - 측정률이 부족하면 측정 방법을 바꿔야 한다 (예: 마이크로 모터 소리를 분석하는 오디오 스펙트럼). 이것도 물리 탐구에서 다룰 수 있는 "문제 발견"이다.

| ✅ TCA9548A 멀티플렉서 | 1 | — | |
| ✅ Arduino Mega, Uno | 각 1 | — | 개발은 Mega 권장 |
| 진동 모터 모듈 (MOSFET 내장, VCC·GND·IN) | 6 + 여분 2 | **지금 주문** | 위 '진동 모터 → 모듈로 교체' 참고. 처음 산 코인 모터는 리드선 문제로 교체 |
| 핀헤더 + 납땜 장비 | 1세트 | **1주차** | 센서와 멀티플렉서에 핀헤더 납땜. 동아리실 장비가 있는지 먼저 확인 |
| 점퍼선 (수–수, 수–암, **암–암**) | 넉넉히 | **1주차** | 핀헤더끼리 연결할 때는 암–암이 필요하다 |

| 멀티미터 | 1 | 1주차 | 전압, 끊어진 선, 배선 확인. 동아리실 것이 있으면 생략 |
| 전해 커패시터 100µF (16V 이상) | 2 | 3주차 | 모터 전원 안정화 |
| 5V 보조배터리 + USB 브레이크아웃 보드 (또는 USB 케이블을 잘라 사용) | 1 | 3주차 | 모터 전원 분리. ⚠️ 아래 "보조배터리 주의" 참고 |
| 수–암 점퍼선 20 cm 이상 | 18 이상 | 3주차 | 모듈 6개 × 3핀 (VCC, GND, IN). 착용 위치가 정해지면 필요한 길이로 바꾼다 |
| 얇은 3심 전선 (또는 리본 케이블) | 약 3 m | 6주차 | 최종 조립 때 몸 유닛 ↔ 모듈 연결 (VCC, GND, IN) |
| 열수축 튜브 | 조금 | 6주차 | 전선 연결부 보호 |
| 4심 케이블 약 1 m | 1 | 6주차 | 머리 유닛 ↔ 아두이노 (VCC, GND, SDA, SCL) |
| 만능기판 + 핀헤더 | 1세트 | 6주차 | 최종 조립용 (브레드보드는 착용 중 빠진다) |

**보조배터리 주의:** 보조배터리는 흐르는 전류가 작으면 스스로 꺼지는 제품이 많다. 진동이 짧게 끊어지는 패턴(80 ms 켜짐)에서는 평균 전류가 작아 꺼질 수 있다.
- 살 때: "저전류 모드" 또는 "항상 켜짐" 기능이 있는지 확인한다.
- 3주차에 확인: 모터 1개를 1단계 패턴(80 ms / 700 ms)으로 2분 이상 돌려서 배터리가 꺼지지 않는지 본다.
