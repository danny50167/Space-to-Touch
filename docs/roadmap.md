# 제작 로드맵 (2026.10.12 ~ 12.31)

**원칙:** 매 단계마다 "측정 → 문제 발견 → 원인 분석 → 개선"을 기록한다. 실패한 시도도 반드시 남긴다.
**일정:** 제작과 실험은 **12월 첫째 주까지** 끝내고(기말고사 전), 기말고사 후에 활동 보고서를 완성해 **12월 말**에 제출한다.

> 학교 시험 일정에 맞춰 주차를 조정한다. 4~5주차(기구 설계)가 가장 오래 걸리므로 미루지 않는다.
>
> **교과 연계 실험(⭐ 표시)은 발표 날짜와 상관없이 11/8까지 끝낸다.** 발표가 언제 잡혀도 데이터가 준비되어 있도록.

## 0. 부품 확인 (이번 주 안에)
- [ ] `docs/parts.md` 목록을 보고 부족한 것을 확인하고 주문한다. 3주차 전에 도착해야 한다.

## 1주차 (10/12–10/18) 센서 1개 이해하기
- [ ] 라이브러리 설치, `01_single_sensor_test` 업로드
- [ ] 거리 모드(Short / Medium / Long)별로 실제 거리 30, 50, 100, 150, 200 cm에서 평균과 표준편차 측정
- [ ] 흰 종이 / 검은 천 / 유리처럼 표면을 바꿔 측정
- **기록:** 실측값 vs 측정값 표와 오차 그래프 → 사용할 거리 모드 결정과 그 이유
- 연계: 빛의 속력과 비행시간 (1 m 왕복 ≈ 6.7 ns)

## 2주차 (10/19–10/25) 센서 6개 + 멀티플렉서
- [ ] 멀티플렉서 배선, `02_six_sensors_mux` 업로드
- [ ] **평행 배치** 상태에서 물체를 좌→우로 옮기며 6개 값을 기록한다 → 방향 구분이 안 되는 것을 데이터로 확인 (**핵심 "문제 발견"**)
- [ ] 순차 측정 vs 연속 측정: 갱신 속도(Hz)와 값의 흔들림(표준편차) 비교
- [ ] ⭐ **접근 실험 (미적분Ⅰ):** 센서 하나를 들고 벽을 향해 느리게 / 보통 / 빠르게 걸으며 `02` 스케치의 CSV(시간, 거리)를 저장한다. 속도마다 3회 이상
- **기록:** 평행 배치의 겹침 문제 데이터, 측정 방식 결정과 그 이유, 접근 실험 CSV

## 3주차 (10/26–11/1) 진동 모터와 착용 위치 실험
- [ ] 트랜지스터 구동 회로 6세트 제작 (`docs/wiring.md`)
- [ ] ⭐ **모터 진동 특성 측정 (물리):** 스마트폰을 모터에 붙이고 **phyphox** 앱(가속도 센서)으로 듀티비별 진동수와 진폭 측정
- [ ] 모터 6개를 이마 / 팔뚝 / 복부에 임시로 붙인다 (테이프, 밴드)
- [ ] `03_motor_localization_test`: 부위마다 30회 시행, 참가자 2~3명
- [ ] 참가자는 안대와 백색소음 이어폰을 착용한다 (모터 소리로 위치를 맞히지 못하게 통제)
- [ ] ⭐ **두 점 역치 (생명):** 같은 참가자, 같은 부위에서 컴퍼스로 두 점 역치를 측정해 진동 위치 인식 결과와 비교
- **기록:** 듀티비–진동수 그래프, 부위별 정확도와 혼동 행렬 → 착용 위치 결정 (**데이터 기반 설계 결정**)
- 연계: 편심 회전의 원심력 (물리), 피부 감각 수용기와 감각 순응 (생명)

## 4~5주차 (11/2–11/15) Fusion 360 기구 설계 (PLA)
- [ ] ⭐ **접근 실험 분석 (미적분Ⅰ, 11/8까지):** 거리–시간 데이터의 평균변화율로 접근 속도를 구하고, "충돌까지 남은 시간 = 거리 ÷ 접근 속도"를 계산한다. Δt를 바꾸면 잡음과 반응 지연이 어떻게 달라지는지 비교
- [ ] 키와 감지 높이로 센서 각도 계산 (`docs/design-notes.md` 1장)
- [ ] **헤드 마운트 v1 = 각도 조절형:** 센서마다 M3 볼트 힌지로 각도를 바꿀 수 있게 설계한다 (`design-notes.md` 4장)
- [ ] 실험으로 최적 각도 찾기 → **v2 = 그 각도로 고정한 일체형**
- [ ] 진동 밴드: PLA 모터 홀더 + 고무 밴드 + 폼 진동 격리
- [ ] ⭐ 진동 격리 검증 (물리, 11/8까지): phyphox로 옆 모터 위치에서 진동이 얼마나 전달되는지 측정 (폼 있음 / 없음)
- [ ] 감지 영역 검증: 아래 줄 센서가 바닥이나 벽에서 감지하는 경계를 측정하고 계산값(이차곡선)과 비교
- **기록:** 설계 도면 캡처, 계산 과정, 계산값 vs 실측값, 진동 전달률 비교
- 고려: 머리 유닛 무게와 무게중심 (목에 걸리는 부담), 착용 편의
