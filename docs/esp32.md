# ESP32 사용법

## 왜 ESP32로 바꿨나 (11/10 결정)
- 학생이 제안했다. 처음에는 가진 Arduino Mega로 개발하려고 했다.
- **걸으면서 하는 실험이 많다**: 접근 실험(3단계), 걸을 때 고개 각도(7단계), 사용자 실험(8단계). USB 선을 노트북에 꽂은 채 걸으면 걸음이 자연스럽지 않다.
  ESP32는 Wi-Fi로 데이터를 맥북에 바로 보낸다.
- Mega보다 훨씬 작고 가벼워서 착용형(v2)에 맞다. 메모리도 넉넉하다.
- 처음 쓰는 보드라서, 센서를 연결하기 **전에** 이 문서 1~3장을 먼저 해 본다.
- Mega·Uno는 예비로 둔다. 펌웨어는 세 보드에서 모두 돌아간다 (보드를 알아서 구분해 핀 번호를 바꾼다).
- 블루투스 대신 Wi-Fi를 쓰는 이유: 맥에서는 블루투스 시리얼 연결이 불안정하다는 보고가 있다. Wi-Fi는 맥 기본 프로그램(터미널)만으로 받을 수 있다.

## Mega와 다른 점
| | ESP32 | Mega |
|---|---|---|
| 신호 전압 (HIGH) | **3.3V** | 5V |
| I2C 부품 전원 | **3.3V 핀** | 5V 핀 |
| SDA / SCL | GPIO 21 / 22 | 20 / 21 |
| 진동 모터 핀 (0·1·2) | GPIO 25 / 26 / 27 | 2 / 3 / 5 |
| 데이터 받기 | USB 또는 **Wi-Fi** | USB만 |

⚠️ ESP32 핀에 5V를 넣으면 고장 날 수 있다. 배선은 `docs/wiring.md`를 따른다.

## 1. 맥북에 설치하기
1. Arduino IDE 2를 설치한다.
2. 왼쪽 **보드 매니저**에서 `esp32`를 검색해 **esp32 by Espressif Systems**를 설치한다.
   - 목록에 없으면 Arduino IDE → 설정 → "추가 보드 관리자 URL"에 아래 주소를 넣고 다시 검색한다.
     `https://espressif.github.io/arduino-esp32/package_esp32_index.json`
3. **라이브러리 매니저**에서 `VL53L1X` (by Pololu)를 설치한다 (Mega 때와 같다).

## 2. 첫 업로드 (아무것도 연결하지 않고)
1. ESP32를 **데이터용** USB 케이블로 맥북에 꽂는다.
2. 도구 → 보드 → esp32 → **ESP32 Dev Module**을 고른다.
3. 도구 → 포트에서 `/dev/cu.usbserial-…` 또는 `/dev/cu.wchusbserial-…`을 고른다.
   - 포트가 안 보이면: 케이블이 충전 전용인지 확인한다 → 보드의 USB 칩(CP2102 또는 CH340) 드라이버를 설치한다.
4. `firmware/00_i2c_scan`을 업로드한다. 시리얼 모니터(115200 baud)에 "장치 없음"이 나오면 성공이다. 아무것도 연결하지 않았으니 정상이다.
   - 업로드 중 `Connecting....`에서 멈추면 보드의 **BOOT 버튼**을 누른 채로 기다리다가, 업로드가 시작되면 뗀다.
   - DevKitC는 보드에 깜빡이는 LED가 없는 제품이 많다. 그래서 Blink 대신 이 방법으로 확인한다.

## 3. 무선으로 데이터 받기
`02_three_sensors_mux`, `04_space_to_touch`, `05_imu_tilt`는 USB와 Wi-Fi로 같은 내용을 내보낸다 (스케치 폴더의 `wifi_log.h`).

1. 셋 중 하나를 업로드한다. 센서가 없어도 연습할 수 있다 (`02`는 "멀티플렉서를 찾을 수 없음"까지만 나온다).
2. ESP32를 보조배터리에 꽂는다. USB 선을 빼도 된다.
3. 맥북 Wi-Fi 목록에서 **SpaceToTouch**에 연결한다. 비밀번호는 `touch1234`다.
   - 이 Wi-Fi에 연결된 동안 맥북은 인터넷이 안 된다. "인터넷 연결 없음"이라고 떠도 정상이다.
4. 터미널을 열고, 저장할 폴더로 이동한 뒤 받기 시작한다.
   ```bash
   cd ~/Desktop
   ```
   ```bash
   nc 192.168.4.1 2323 | tee approach_slow_1.csv
   ```
   - 화면에 데이터가 나오면서 같은 내용이 파일에 저장된다.
   - 그 창에 `c`, `q`, `z`, `d` 같은 명령을 치고 Enter를 누르면 시리얼 모니터처럼 ESP32에 보내진다.
   - 끝낼 때는 `Ctrl + C`를 누른다. 다음 회차는 파일 이름만 바꿔 다시 실행한다.
5. 엑셀(또는 Numbers)로 CSV를 연다. `#`으로 시작하는 줄은 설명이라서 지우고 분석한다.

**파일 이름 규칙:** `실험_조건_회차.csv` (예: `approach_fast_3.csv`, `imu_walk_1.csv`). 영어와 숫자만 쓰면 엑셀에서 덜 헷갈린다.

## 4. 실험 전에 확인할 것 (일지에 남긴다)
- [ ] **끊김:** `05_imu_tilt`를 1분 동안 받아서 시간(ms) 열의 간격이 거의 20 ms로 일정한지 본다. 중간에 크게 비는 곳이 있으면 몇 번, 얼마나 비었는지 적는다.
- [ ] **거리:** ESP32를 들고 맥북에서 5 m, 10 m 떨어져 걸어 본다. 데이터가 끊기는 거리를 적는다. 접근 실험은 그보다 가까운 곳에서 한다.
- [ ] **USB와 비교:** 같은 측정을 USB로도 받아서 무선과 결과가 같은지 확인한다.

## 문제 해결
| 증상 | 확인할 것 |
|---|---|
| 포트가 안 보인다 | 데이터용 케이블인지, USB 칩 드라이버를 설치했는지 |
| `Connecting....`에서 멈춘다 | BOOT 버튼을 누른 채 업로드 |
| Wi-Fi 목록에 SpaceToTouch가 없다 | 보드에 전원이 들어왔는지, `02`·`04`·`05` 중 하나를 올렸는지 (`00`, `01`, `03`은 Wi-Fi를 켜지 않는다) |
| `nc`가 아무것도 안 받는다 | 맥북이 SpaceToTouch에 연결돼 있는지. `nc`를 끄고 다시 실행한다 |
| 받다가 멈춘다 | 너무 멀리 갔는지. `nc`를 다시 실행하면 다시 받는다 (ESP32는 새 연결을 기다린다) |
| 모터가 약하게 돈다 | 모듈이 3.3V 신호로 완전히 켜지지 않는 것일 수 있다. IN 선을 ESP32 핀에서 뺀 뒤, ESP32 3.3V 핀에 직접 연결할 때와 보조배터리 5V에 직접 연결할 때 세기를 비교한다 (`docs/wiring.md` 2장) |
