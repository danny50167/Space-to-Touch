# 설계 노트

여기 적힌 숫자는 **출발점**이다. 최종 값은 실험으로 직접 정하고, 바꾼 이유를 일지에 남긴다.
면접에서 "왜 이렇게 설계했나요?"라는 질문에 답할 근거가 바로 이 기록이다.

---

## 1. 센서 각도 설계

### 1-1. 왜 각도를 줘야 하나
VL53L1X의 시야각(FoV)은 약 **27°** 이다. 거리 d에서 센서 하나가 보는 폭은 다음과 같다.

```
폭 = 2 · d · tan(27° / 2) ≈ 0.48 · d      (1 m 앞에서 약 48 cm)
```

센서를 3 cm 간격으로 **평행하게** 붙이면 1 m 앞에서 두 시야가 3 cm만 어긋나므로 **약 94% 가 겹친다.**
결국 6개가 같은 곳을 보게 되어 방향 정보가 사라진다.
→ **실험 과제:** 평행 배치 상태에서 물체를 좌우로 옮기며 6개 값이 얼마나 비슷한지 측정해 둔다 (문제 발견 데이터).

### 1-2. 가로 방향 (왼쪽 / 가운데 / 오른쪽)
- 출발점: 가운데 0°, 좌우 **±27°**. 이러면 전방 약 81°를 빈틈 없이 덮는다.
- 각도를 줄이면 겹침이 늘고, 키우면 사이에 빈틈이 생긴다. **빈틈 폭을 직접 계산**해 볼 것.
- 머리에 달기 때문에 사용자가 **고개를 돌려 주변을 훑을 수 있다.** 이 점이 머리 착용의 큰 장점이다.

### 1-3. 세로 방향 (위 줄 / 아래 줄)
머리(센서) 높이를 H, 아래로 기울인 각을 θ라 하면, 수평 거리 x 지점에서 시야 중심선의 높이는 다음과 같다.

```
높이(x) = H − x · tan θ
바닥에 닿는 수평 거리 = H / tan θ
```

예: H = 1.6 m, θ = 20° 이면
- x = 1.5 m 지점에서 높이 약 1.05 m
- x = 2.0 m 지점에서 높이 약 0.87 m → 책상, 의자 등받이 높이
- 바닥에는 약 4.4 m 앞에서 닿는다 (사실상 측정 범위 밖)

**출발점:** 위 줄 0° (머리~가슴 높이), 아래 줄 아래로 20° (허리 높이).
**학생이 정할 것:** 학생의 실제 키와 감지하고 싶은 장애물 높이로 θ를 다시 계산한다.

### 1-4. 알려진 한계 (보고서에 꼭 적을 것)
- 걸을 때 고개가 위아래로 ±10° 정도 흔들리면 아래 줄이 보는 높이도 같이 흔들린다.
  - 확장 아이디어: IMU(가속도·자이로 센서)로 고개 각도를 보정한다.
- 유리, 거울, 검은 천은 적외선이 잘 반사되지 않아 측정이 부정확하다.
- 6개 센서의 시야가 겹치면 서로의 적외선이 간섭할 수 있다 → `02` 스케치로 순차 측정과 연속 측정을 비교한다.

### 1-5. 기하 연계
원뿔 모양의 시야가 바닥 평면과 만나는 경계는 **이차곡선(타원)** 이 된다.
센서 방향을 **공간벡터**로 놓고 바닥에 생기는 타원을 구하면, 아래 줄이 바닥에서 감지하는 영역을 정확히 계산할 수 있다.

### 1-6. ROI 기능 (선택)
VL53L1X는 내부 16×16 SPAD 중 일부만 쓰도록 **ROI(관심 영역)** 를 줄일 수 있다 (`setROISize`).
ROI를 줄이면 시야각이 좁아져 겹침이 줄어드는 대신 신호가 약해진다. 각도 조정과 비교해 볼 수 있는 대안이다.

## 2. 진동 모터 착용 위치

센서는 머리에 달지만 모터를 꼭 머리에 달 필요는 없다. **데이터로 정한다.**

| 후보 | 예상 장점 | 예상 단점 |
|---|---|---|
| 이마 (헤드밴드) | 센서와 같은 위치라 가장 직관적 | 진동이 두개골을 타고 퍼짐, 세로 간격 확보가 어려움, 불쾌감 |
| 팔뚝 (슬리브) | 착용이 쉬움 | 폭이 좁아 가로 3칸 배치가 어려움, 좌우 대응이 덜 직관적 |
| 복부 (벨트) | 넓어서 간격 확보가 쉽고 좌우 대응이 자연스러움 | 옷 위에서는 진동이 약해짐 |

- 모터 간격은 **4~5 cm 이상**에서 시작한다. 진동 자극은 정적 압력보다 위치 구분이 어렵다.
- 모터와 밴드 사이에 **폼이나 실리콘을 넣어 진동이 옆으로 퍼지지 않게** 한다 (진동 격리).
- **실험:** `03_motor_localization_test`로 부위별 위치 인식 정확도와 혼동 행렬을 비교한다. 어느 모터끼리 헷갈리는지가 드러난다.

### 물리·생명 연계
- 코인 모터(ERM)는 **편심 질량의 회전**으로 진동한다. 원심력은 F = m·r·ω² 이다.
  - 그래서 진동 세기와 진동수를 따로 조절할 수 없다 (전압을 올리면 둘 다 커진다). 이것이 ERM의 구조적 한계다.
- 피부의 **파치니 소체**는 약 200~300 Hz 진동에 가장 민감하다. 사용하는 모터의 진동수와 비교해 볼 것.
- 같은 자극이 계속되면 **감각 순응**으로 둔해진다 → "먼 물체는 진동하지 않음" 설계의 근거가 된다.

## 3. 거리 → 진동 표현 방식

사람은 진동 **세기**의 차이보다 **리듬(간격)** 의 차이를 더 잘 구분한다. 자동차 후방 경고음과 같은 방식을 쓴다.

| 단계 | 거리 (출발점) | 패턴 |
|---|---|---|
| 0 | 1500 mm 이상 / 감지 없음 | 진동 없음 |
| 1 | 1000 ~ 1500 mm | 짧게 "띠…" (80 ms 켜짐 / 700 ms 주기) |
| 2 | 500 ~ 1000 mm | "띠띠띠" (80 ms / 300 ms) |
| 3 | 500 mm 미만 | 계속 진동 |

- **중앙값 필터 (3개):** 튀는 값 하나를 무시한다.
- **히스테리시스 (50 mm):** 경계 거리에서 단계가 깜빡이지 않게 한다. 가까워질 때는 즉시 반응하고, 멀어질 때만 여유를 둔다.
- **고장 알림:** 센서가 응답하지 않으면 모든 모터를 짧게 두 번 울린다. 고장 상태에서 아무 진동이 없으면 사용자는 "앞이 비었다"고 오해한다 → **안전 설계(fail-safe)**.

### 반응 속도
- 실내에서 안대를 쓰고 걸으면 보행 속도는 약 0.7 m/s다.
- 연속 측정 모드에서 센서들은 **동시에** 측정하므로 각 센서가 약 20 Hz로 갱신된다 (타이밍 버짓 50 ms 기준).
- 순차 측정이면 6배 느려진다. 두 방식의 측정값을 `02` 스케치로 직접 비교할 것.
