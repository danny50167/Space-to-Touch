# CAD 파일

## reference/ : 구입 부품의 참고용 모델 (STEP)
홀더와 센서 바를 설계할 때 Fusion 360에 불러와 **끼워 맞춰 보는 용도**다. 출력하는 부품이 아니다.

| 파일 | 내용 |
|---|---|
| `vl53l1x_module_ref.step` | VL53L1X 모듈 (판매처 도면: 20 × 12 mm, M2 구멍 간격 16 mm, 핀 6개) |
| `vl53l1x_fov_cone_60mm.step` | 센서 시야 원뿔 (27°, 길이 60 mm). 홀더나 바가 이 원뿔과 겹치면 시야를 가린다 |
| `gy521_mpu6050_ref.step` | MPU-6050 모듈 GY-521 (21.2 × 16.4 mm, M3 구멍 2개) |

- 좌표: 단위 mm. **칩 윗면 중심이 원점**, 센서가 보는 방향이 +Z. 원뿔도 같은 원점에서 시작하므로 그대로 겹쳐진다.
- Fusion 360에서 여는 법: 데이터 패널 → 업로드 → STEP 파일 선택 → 열린 디자인을 내 설계에 "현재 디자인에 삽입"한다.
- 위치를 잡을 때는 조인트(Joint)로 붙이고, 겹침 확인은 검사 → 간섭(Interference)으로 한다.

### 가정한 값 (실측 후 고친다)
| 항목 | 지금 값 | 근거 |
|---|---|---|
| 기판 두께 | 1.6 mm | 흔한 PCB 두께 (가정) |
| VL53L1X 칩 위치 | 부품 영역 가운데 | 도면에 없음 |
| VL53L1X 핀 줄 위치 | 아래 가장자리에서 1.0 mm | 도면 비율로 읽음 |
| GY-521 구멍 위치 | 핀 반대쪽 가장자리에서 2.6 mm, 간격 15.5 mm | 판매처 1곳 + 추정 |
| GY-521 칩 위치 | 가운데 | 가정 |

- 뒷면 부품과 핀헤더는 넣지 않았다. 납땜 후 길이와 방향을 재서 공간을 남긴다.
- 값을 바꾸려면 `make_reference.py` 위쪽 숫자를 고치고 다시 실행한다 (CadQuery 필요).

## 학생이 설계하는 부품
센서 홀더, 쐐기 블록, 센서 바는 학생이 Fusion 360에서 직접 설계한다 (`docs/design-notes.md` 4장). 설계 파일(.f3d)과 출력용 STL도 이 폴더에 버전별로 저장한다 (예: `holder_v1.f3d`).
