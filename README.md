# Space-to-Touch

시각장애인을 위한 **전방 공간 정보 → 촉각 변환 장치**.
머리에 착용한 ToF 거리 센서 6개(3×2)가 전방을 측정하고, 같은 3×2 배열의 진동 모터가 장애물의 **방향**과 **거리**를 진동으로 알려준다.

> 흰지팡이는 바닥의 장애물은 잘 찾지만 **허리 위 장애물(간판, 선반, 열린 창문 등)** 은 감지하지 못한다.
> 이 장치는 지팡이를 대체하는 것이 아니라, 지팡이가 못 하는 부분을 **보완**하는 것을 목표로 한다.

## 시스템 구성

```
 [머리 유닛]                               [몸 유닛]
 VL53L1X ×6 ── TCA9548A ── 4선 케이블 ──── Arduino Mega / Uno ── 구동 회로 ×6 ── 코인 진동 모터 ×6
 (3D 프린팅 브래킷)    (VCC, GND, SDA, SCL)                         (트랜지스터 + 다이오드)
```

센서 번호와 모터 번호는 같은 규칙을 쓴다. 멀티플렉서 채널 번호도 같다.

```
          왼쪽   가운데   오른쪽
 위 줄      0      1       2      ← 머리~가슴 높이
 아래 줄    3      4       5      ← 허리 높이 (아래로 기울임)
```

## 시작하기

1. Arduino IDE → 라이브러리 매니저에서 **"VL53L1X" (by Pololu)** 를 설치한다.
2. `firmware/01_...` 부터 순서대로 업로드하며 진행한다. 각 스케치 맨 위 주석에 사용법이 있다.
3. 시리얼 모니터는 **115200 baud**, 줄 끝은 "새 줄(Newline)"로 설정한다.
